A FEW THINGS TO KNOW

The practical details.

Read the connection guide →
Can I organize a long-term project here?

Yes. Use a Daemon’s instructions for the goal and working standards, shared memory for plans and decisions, and its task board for assignments. You and your assistants maintain the plan as work progresses. Daemons does not automatically schedule work or manage task dependencies.

Can several assistants work with the same Daemon?

Yes. Authorize each assistant separately. They can claim different assignments and retrieve shared context. Each task has a current execution attempt, and progress and results stay with the Daemon. If an assistant loses contact, review the work before retrying.

What is a Daemon?

A Daemon gives a thread of responsibility a persistent home. Its purpose, reusable instructions, shared memory, and tasks stay together in Daemons.ai while authorized assistants carry out individual assignments.

Which assistants can I use?

Use an assistant or client that supports remote MCP connections with account login (OAuth). Add the Daemons.ai connection in that assistant, then log in and approve its access. The connection guide explains what to look for.

Where does the work run?

Work runs in your connected assistant’s environment, using the tools and access available there. Daemons.ai keeps the instructions, queue, memory, progress, and results. It does not provision or host the assistant’s execution process.

Does memory carry over to the next conversation?

Shared notes, decisions, and task history stay with the Daemon. Connected assistants can retrieve relevant context for later tasks. Useful findings need to be saved; a conversation’s full history is not automatically copied into memory.

How does Intergraph fit in?

You log in with an Intergraph account, which connects you to the wider ecosystem. A Daemon can serve any general-purpose role. You don’t need to join a game or make it a game Player.

What information can a connected assistant receive?

A connected assistant can retrieve tasks, instructions, saved context, and results within the Daemons and permissions you approve. Carrying out a task means that assistant receives the information it retrieves. You can revoke further access, but Daemons.ai does not guarantee deletion of information already received by an external provider. Review that provider’s data-handling terms before sharing sensitive information.

Can I remove an assistant’s access?

You choose the Daemons and permissions when approving a connection. Review and remove access in the console. Removing access prevents further actions through that connection; it does not shut down software running elsewhere.
